# 🌌 HARISH.OS — An Interactive 3D Digital Universe

> *"Don't scroll through my portfolio. Explore it."*

**HARISH.OS** is a cinematic, futuristic personal portfolio experience built for **Harish**, a Computer Science Engineering student at SSN College of Engineering and aspiring Java Full Stack Developer.

Instead of a standard portfolio website, HARISH.OS is designed as a living 3D operating system and digital galaxy combining WebGL, Three.js, React Three Fiber, and cybernetic HUD aesthetics.

---

## 🚀 Key Features

* **Cinematic Journey & Camera Navigation**: Scroll and touch gestures serve as a camera controller piloting the visitor through 8 distinct cosmic sectors.
* **Chapter 01 — The Core**: Holographic data sphere representing Harish's identity matrix, orbiting technology satellites, and core engineering philosophy.
* **Chapter 02 — Knowledge City**: Procedural 3D cyberpunk metropolis where each skill is an interactive skyscraper (*Java Tower, Spring Boot Spire, React Lab, SQL Vault, Python Lab, JavaScript Hub, DSA Center*). Clicking any tower reveals its architectural blueprint and syllabus telemetry.
* **Chapter 03 — Project Planets**: An orbital planetary system featuring key projects (*FoodHub, Hospital Management System, Multithreaded Web Crawler, Machine Learning Intelligence, Networking Protocols Lab*). Clicking a planet engages **Warp Speed** to enter the Spacecraft Cockpit mission control view.
* **Chapter 04 — Achievement Constellation**: Astrological 3D constellation with luminous star nodes connected by vector lines, showcasing academic honors, certifications, and 300+ LeetCode DSA milestones.
* **Chapter 05 — Education Archive**: 3D spatial time corridor featuring chronological portals for each academic year at SSN College of Engineering (2023–2027).
* **Chapter 06 — Coding Dimension**: Cyberspace void with floating 3D code fragments drifting through space (*`public class Main`*, *`new HashMap<>()`*, *`@SpringBootApplication`*, etc.) around a rotating cyber hypercube.
* **Chapter 07 — Future Galaxy**: Deep nebula exoplanets showcasing future engineering goals (Cloud & Kubernetes, AI Agents, Distributed System Design, Open Source).
* **Chapter 08 — The Contact Portal**: Giant rotating quantum Stargate with an energy event horizon, quick-connect nodes, and an encrypted dispatch form.
* **Easter Egg Developer Terminal**:
  * Press <kbd>~</kbd>, click **TERMINAL**, or **click the `HARISH.OS` logo 5 times** to activate Developer Mode.
  * Real CLI commands: `help`, `about`, `skills`, `projects`, `education`, `achievements`, `future`, `contact`, `warp <1-8>`, `matrix`, `easteregg`, `cls`.
* **Procedural Web Audio Engine**: Synthesized real-time sci-fi sound effects (engine drone, warp whoosh, UI chirps, and mechanical keystrokes) built using the Web Audio API with zero external audio assets.
* **Sci-Fi HUD & Orbital Radar**: Live sector coordinates telemetry, chapter progress indicator, and rotating orbital minimap scanner.

## 🛠️ Tech Stack

* **Frontend Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
* **3D Graphics & WebGL**: [Three.js](https://threejs.org/) + [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber/) + [@react-three/drei](https://github.com/pmndrs/drei)
* **Audio**: Procedural Web Audio API Synthesizer
* **Icons & Effects**: [Lucide React](https://lucide.dev/), [Canvas-Confetti](https://www.npmjs.com/package/canvas-confetti)
* **Typography**: Orbitron, Rajdhani, JetBrains Mono, Space Grotesk

## 📦 Getting Started

### Prerequisites
* Node.js (v18+ recommended)
* npm

### Installation
```bash
# Clone the repository
git clone https://github.com/harishravi10/portfolio.3d.git

# Navigate to project directory
cd portfolio.3d

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Build for Production
```bash
npm run build
npm run preview
```
